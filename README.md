# Financial Performance Analysis of BRAC Bank (2020–2023)

## Project Overview

This project focuses on analyzing the financial performance of BRAC Bank using annual report data from 2020 to 2023. The objective was to evaluate the bank’s profitability, shareholder returns, lending efficiency, solvency, and overall business growth through financial ratio analysis and dashboard visualization.

An interactive dashboard was developed using Power BI to present key financial insights in a clear and professional format.

---

## Objectives

* Analyze BRAC Bank’s financial performance over four years
* Evaluate profitability and operational efficiency
* Measure shareholder return and solvency position
* Compare deposits and loans growth trends
* Build a professional dashboard for financial decision-making insights

---

## Tools Used

* Microsoft Excel
* Power BI
* Financial Ratio Analysis
* Annual Report Data Analysis

---

## Key Performance Indicators (KPIs)

* Highest Net Profit
* Best ROE Year
* Highest EPS
* Deposit Growth Rate
* Asset Growth Rate
* Debt to Equity Ratio
* Loan to Deposit Ratio

---

## Financial Ratios Analyzed

* Return on Assets (ROA)
* Return on Equity (ROE)
* Debt to Equity Ratio
* Loan to Deposit Ratio
* Net Profit Trend
* Deposit Growth Rate
* Asset Growth Rate
* Earnings Per Share (EPS)

---

## Key Findings

* Net profit increased steadily from 2020 to 2023, indicating strong profitability growth
* ROE reached its highest level in 2023, reflecting improved shareholder returns
* Deposit growth accelerated significantly, showing stronger customer confidence
* Loan to Deposit Ratio remained stable, suggesting balanced lending efficiency
* Asset growth confirmed strong business expansion and operational scale
